ABOUT THE PROJECT

What's under the hood

AttritionIQ is a full-stack HR analytics demo: a Flask backend serving a scikit-learn Random Forest model, wrapped in a dashboard UI built for real HR workflows.

The Model

A Random Forest Classifier ({{ metrics.n_estimators }} trees, max depth 10, balanced class weights) trained inside a scikit-learn Pipeline that also handles one-hot encoding for categorical fields. The whole pipeline is serialized with joblib as a single model.pkl, so the Flask app never has to re-implement preprocessing.

The Data

A synthetic dataset of {{ "{:,}".format(metrics.dataset_size) }} employee records, generated with domain-informed probability rules (overtime, low satisfaction, poor work-life balance, low pay, and long commutes raise risk) so the resulting patterns mirror published HR attrition research. Overall attrition rate: {{ metrics.attrition_rate }}%.

The Stack

Flask serves the routes and templates; scikit-learn trains and scores; joblib persists the model; vanilla HTML/CSS/JS builds the interface — no frontend framework required. Gunicorn runs it in production.

PythonFlaskscikit-learnpandasjoblibGunicorn

Limitations

This model is trained on synthetic data for demonstration purposes. It should not be used to make real employment or HR decisions. In production, this would be retrained on de-identified, consented, real employee data with fairness and bias auditing built in.
